# LanguageLeap — платформа для изучения иностранных языков

**LanguageLeap** — веб‑система для интерактивного изучения языков, построенная на **Django + PostgreSQL** с использованием **JavaScript** для клиентской интерактивности. Платформа объединяет чтение учебных текстов, работу со словарём, сохранение и повторение слов, а также аналитику прогресса и активности пользователя.

---

## **Ключевой функционал**



### 1) **Обучение на текстах**
*текст* - центральная единица обучения: пользователь читает материал, сохраняет неизвестные слова и фиксирует прогресс.

**Основные возможности:**
- Добавление собственных текстов, возможность добавить аудио или автоматически сгенирировать его.
- Удобное отображение текста, возможность прослушивать аудио и просматривать неизвестные слова.
- Интерактивное чтение текстов с возможностью перевода и сохранения неизвестных слов или фраз.
- Каталог уже добавленных другими пользователями текстов, возможность поиска и сортировки по уровню, хит-парад самых популярных текстов за неделю, месяц, год и все время.




### 2) **Словарь и работа со словами**

Обеспечено хранение сохраненнй лексики, заучивание и экспорт новых слов.

**Основные возможности:**
- Слова из текста переводятся с учетом контекста, помимо перевода пользователь может просмотреть определение на иностранном или русском языке, список синонимов и антонимов, пример использования в предложении и перевод этого примера.
- Переведенные слова автоматически сохраняются как неизвестные, пользователь получает возможность изучать или экспортировать неизвестные слова.
- У пользователя есть возможность отслеживать свой прогресс: сколько слов было сохранено и выучено.





### 3) **Профиль пользователя**

Обеспечение отслеживания прогресса, сохранение текстов, взаимодействие с другими пользователями
- Пользователь имеет возможность сохранять тексты и удобно просматривать созраненные и добавленные самим пользователем тексты в профиле.
- Пользователь имеет возможность отслеживать собственный прогресс:  тепловая карта активности по дням помогает видеть регулярность занятий, графики прогресса позволяют увидеть сколько слов уже было выучено и сохранено, а также как этот показатель менялся со временем.
- Пользователь может добавлять в друзья других пользователей, сравнивать свои результаты с результатами друзей, просматривать прогресс друзей, что помогает поддерживать мотивацию.

## Технологический стек

| Слой | Технологии (по документации) | Назначение |
|---|---|---|
| Backend | **Django** | бизнес‑логика, авторизация, API, управление данными |
| DB | **PostgreSQL** | хранение пользователей, текстов, слов, прогресса, связей |
| Frontend | **JavaScript** | интерактивность интерфейса |
| Визуализация | **Chart.js**, **Cal-heatmap**, **Grid.js** | графики/тепловые карты/таблицы |
| AI | **Gemini API**, `genai` | перевод/обработка языка |
| Speech | **gTTS** | генерация аудио/озвучки |
